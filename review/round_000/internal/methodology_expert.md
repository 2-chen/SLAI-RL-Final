# Internal Review: Methodology Expert

## Methodology Review

### Strengths (3-5)

1. **清晰的实验框架设计**：三条管线（Identity, DQN-only, SSL→DQN）的对比设计逻辑清晰，变量控制良好。通过冻结随机 MLP 作为不可逆传感器映射是巧妙的设计，有效隔离了"观测维度"这个自变量。

2. **可复现性**：方法部分详细描述了超参数配置（Double DQN 的完整参数表）、环境设置（GridWorld 规格、BFS 最短路径）、以及种子管理策略。理论上具备完全可复现的条件。

3. **问题定义明确**：将"观测维度对样本效率的影响"作为核心研究问题，配合 SSL 作为干预变量，研究框架简洁而有针对性。

4. **理论直觉与前人工作一致**：SSL→DQN 管线中 autoencoder 的瓶颈层（64 维）自然匹配真实状态维度的设计是合理的，符合信息瓶颈理论的基本预期。

### Weaknesses (3-5)

1. **环境过于简单，方法论贡献有限**：8×8 GridWorld 仅有 64 个离散状态，问题规模极小。在如此简单的环境中，autoencoder 学习随机投影的逆映射本质上是学习一个固定的线性代数问题（W 是已知的线性映射，64→M→64），这在高维真实场景中不具有代表性的挑战。

2. **理论分析严重缺失**：论文完全是实证研究，没有任何理论分析。对于"为什么 SSL 能缓解维度灾难"这个问题，论文仅在讨论部分给出了定性的推测（流形假设、隐式正则化、特征线性化），缺乏严谨的数学论证。例如，可以分析随机投影矩阵 W 的奇异值谱与 autoencoder 重建能力的关系。

3. **随机投影类型太单一**：W 是纯线性随机投影。但论文讨论部分提到"特征线性化"时出现矛盾——原文致"随机投影 W 是非线性的（no，纯线性）"，这表明作者在写作过程中意识到了线性性的问题但未修正。纯粹的线性映射到 M 维再降回 64 维本质上是低秩矩阵恢复问题，autoencoder 在此类问题上的优势是已知的，新颖性不足。

4. **SSL 管线设计存在信息泄漏**：Autoencoder 在所有 64 个状态的观测上训练。在实际 RL 场景中，agent 无法枚举所有状态（状态空间通常巨大或连续），因此 SSL 预训练的这种方式在真实场景中不可行。这严重限制了结论的泛化性。

5. **缺少关键的消融实验**：没有探究 bottleneck 维度（固定为 64）的选择是否关键。如果 bottleneck 设为 32 或 128，结果如何？如果 bottleneck 维度也变化，是否能揭示更多机制？

### Detailed Issues (with PROBLEM→IMPACT→FIX format)

**[PROBLEM 1] SSL 预训练使用所有 64 个状态的枚举观测 → [IMPACT]** 在实际 RL 中 agent 无法枚举所有状态，这使 SSL→DQN 管线在与 DQN-only 比较时享有不公平的优势——SSL 管线获得了"免费"的全局状态信息，而 DQN-only 只能通过探索逐步收集观测。**→ [FIX]** 应该使用从回放 buffer 中逐步收集的观测来训练 autoencoder（online SSL），或在实验设置中明确声明这一限制，并增加 online SSL 的对比实验。

**[PROBLEM 2] 理论分析完全缺失 → [IMPACT]** 纯实证论文在 CCF-A 级别会议中竞争力不足。当前论文仅报告了现象，未解释机制。**→ [FIX]** 至少应添加：(a) 对随机投影矩阵 W 的谱分析；(b) autoencoder 潜在表示的线性可分性分析（如线性探测准确率 vs M）；(c) 信息论角度分析（互信息 I(o; s) 与 M 的关系）。

**[PROBLEM 3] Autoencoder 瓶颈维度固定为 64 → [IMPACT]** 瓶颈维度恰好等于真实状态维度，这构成了一个强先验。我们无法判断 SSL 的好处来自"预训练"还是来自"恰好知道了真实状态维度"。**→ [FIX]** 增加不同 bottleneck 维度（如 8, 16, 32, 96, 128）的实验，探究超参数敏感性。

**[PROBLEM 4] "特征线性化"讨论中的矛盾 → [IMPACT]** 论文原文："随机投影 W 是非线性的（no，纯线性）"——括号内的内容似乎是一处内部批注，表明作者自己也不确定这一论点的正确性。这损害了论文的专业性。**→ [FIX]** 删除该矛盾表述，或重新分析 W 的线性性对 autoencoder 学习的影响。

**[PROBLEM 5] 没有探究观测噪声的影响 → [IMPACT]** 论文仅考虑了线性随机投影带来的维度膨胀。实际传感器观测通常还包含各种噪声（高斯噪声、遮挡噪声等）。缺少噪声实验使结论的适用范围不清晰。**→ [FIX]** 增加在观测上添加高斯噪声的实验变体。

### Score (1-10)
**4 / 10**

### Recommendation: Reject
核心问题：方法论贡献不足以支撑 CCF-A 级别发表。实验环境过于简单（64 状态 GridWorld），理论分析完全缺失，SSL 预处理的信息泄漏问题未被充分讨论。建议大幅扩展实验规模（至少到 Atari 级别复杂度），增加理论分析，并解决 SSL 预训练的现实可行性问题后重新投稿。
